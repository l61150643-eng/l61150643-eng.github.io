java帝国的诞生

语法像c 没有指针 没有内存管理 可移植性（一次编译，到处运行） 面向对象 类型安全 高质量的类库

c++—— ？还是不太一样

实现跨平台:在每个操作系统之上又增加了一个抽象层

java的特性和优势

简单性 不需要引入指针，把指针给屏蔽掉了，不用手动管理内存，JVM 自动垃圾回收，减少内存出错

面向对象

  • 模拟人的思维 ，把现实事物抽象成类和对象。比如：人就是类，张三就是对象
  • 封装、继承、多态是三大核心。
  • 以事物为中心去写代码

可移植性 write once,run anywhere，JVM 实现跨平台

高性能 即时编译

分布式

  • 远程方法调用
  • 支持网络开发，可以调用另一台电脑上的 Java 程序方法
  • 适合做网络、后端服务，现在微服务就是分布式思想的延伸

动态性 反射机制

多线程 交互行为，程序中多个任务并发执行

安全性 防病毒防篡改，运行前内存检查，异常机制

健壮性 程序不容易崩

  • 内存自动回收，避免内存泄漏
  • 编译期、运行期大量检查
  • 异常处理机制

java的三大版本

最大特性，跨平台>>>JVM 虚构的，可跑在所有平台

javaSE 标准版（桌面程序 控制台开发…)

× javaME 嵌入式的开发 手机、小家电

javaEE 企业级 web端 服务器开发

JDK JRE JVM

jdk：java development kit 开发工具包

jre：java runtime environment 编译器 运行时环境

jvm：java virtual machine 虚拟机 小巧cpu
