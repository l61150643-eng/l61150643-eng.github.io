标识符 关键字

Java所有的组成部分都需要名字。给类、变量以及方法起的名字都被称为标识符。

为了方便区分、使用它们！

java关键字：
abstract assert boolean break byte
case catch char class const
continue default do double else
enum extends final finally float
for goto if implements import
instanceof int interface long native
new package private protected public
return strictfp short static super
switch synchronized this throw throws
transient try void volatile while
  1. goto、const：是保留关键字，没有实际使用，预留以后使用。
  2. Java 关键字全部小写，像String不是关键字，是类名。
  3. true、false、null 不是关键字，是字面量，代表固定值，也不能当名字，但不属于关键字。

低————————————–>高

byte,short,char->int->long->float->double

局部变量

变量类型 位置 有没有默认值 是否必须手动初始化 归属
类变量 (static) 类内，方法外，加 static ✅ 有默认值 可以不初始化，JVM 自动填充 属于类，所有对象共享
实例变量 类内，方法外，无 static ✅ 有默认值 可以不初始化，JVM 自动填充 属于单个对象，每个对象独立
局部变量 方法内部 / 代码块 {} 内 ❌ 没有默认值 使用前必须手动赋值，否则编译报错 属于方法，方法执行结束销毁
