数据类型

PHP支持的数据类型包括：

  • 字符串 string

    单引号：内部的内容只是作为字符串

    双引号：如果内部是PHP的变量,双引号会解析里面的变量和转义字符。如果内部是html代码，也会解析成html。
    说白了，单引号里的内容，一定是字符串。双引号里的内容，可能会进行解析。

    如果双引号里变量紧贴文字，要用 {} 包裹：

  • 整数 int

  • 浮点数 float

  • 布尔 bool

  • 数组 array

    用 [] 就不加 array；用 array() 就必须加 array。 不能直接用小括号定义数组

  • 对象

  • NULL

  • 算数运算符：+、-、/、*、%
